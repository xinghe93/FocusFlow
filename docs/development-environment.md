## Rules

All team members must use the same SDK baseline.

Do not upgrade API level without team discussion.

Code requiring API > 24 must not be merged into dev.

Before submitting a Pull Request:

1. Build the project.
2. Check ArkTS errors.
3. Run the affected page.
4. Check git diff.
5. Do not commit local configuration or secrets.
